# Air-Quality-Monitoring
Air quality monitoring using MQ sensors and Arduino.



# Project Title
Air-Quality-Monitoring System

## Description
The Air Quality Monitoring System is an IoT-based project designed to monitor and analyze environmental air quality in real time. The system uses gas and particulate sensors to detect harmful pollutants such as carbon monoxide (CO), ozone (O₃), and particulate matter (PM). The collected data is processed using a microcontroller and displayed through a user-friendly application or dashboard for continuous monitoring.

This project helps in identifying pollution levels in indoor or outdoor environments and provides awareness about air quality conditions. The system is low-cost, portable, and suitable for smart city, industrial, and environmental monitoring applications.

## Components Used
Arduino UNO
MQ Series Gas Sensors (MQ-135)
Ozone (O₃) Sensor (optional)
Particulate Matter (PM2.5/PM10) Sensor
Temperature sensor
Wi-Fi Module (if external communication is required)
LCD/I2C Display (optional)
Breadboard and Connecting Wires
Power Supply 

Software Components:
Arduino IDE
Embedded C / C++ Programming

## Features
Real-time air quality monitoring
Detection of harmful gases and pollutants
Measurement of PM2.5 and PM10 levels
Temperature and humidity monitoring
Wireless data transmission using IoT technology

## Future Improvements
